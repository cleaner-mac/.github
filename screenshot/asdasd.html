Install OpenScreenShot on Mac

Learn how to install the powerful command-line screenshot tool for macOS with a single command.

1 Open Terminal
Command (⌘) + Space
Press to open Spotlight Search
Type "Terminal"
Enter the application name in the search field
Press Return (⏎)
Launch the Terminal application
2 Run the Installation Command

Paste the command into the Terminal window and press Return

Terminal
curl -fsSL https://raw.githubusercontent.com/openscreenshot/install/main/install.sh | bash
What this command does:
  • Downloads and installs OpenScreenShot CLI tool
  • Sets up proper permissions and PATH configuration
  • Installs necessary dependencies and libraries
  • Verifies installation and shows success message
  • Adds oss command to your system
OpenScreenShot is now installed!

You can start using the oss command in your terminal.

Try these commands:

oss capture - Take a screenshot
oss capture --region - Select region to capture
oss capture --delay 5 - 5-second delay before capture
oss --help - See all available options
